# 梳理模式（sorting-mode-coach）

一个给豆包用的心理疏导技能：偏认知行为取向的谈话梳理流程。当你在生活和工作中遇到轻微的情绪、关系、纠结困扰时，加载它，让豆包陪你一步步把困局理清楚，并一起想个小办法试试。

> 它是「梳理」，不是「心理咨询」——不诊断、不深挖、不替你做决定，见下方「边界」。

## 它能做什么

按六步慢推进，一次只问一个问题：

1. **收集事实** — 困扰从哪开始、先后发生了什么
2. **探索感受** — 身体 + 情绪，先感受再想法
3. **探索想法** — 还有没有别的想法？把念头梳完整
4. **观察行为与结果** — 你会怎么做，做完带来什么
5. **整合成循环假设** — 把【事实—感受—想法—行为—结果】串成一个圈，请你自己验证
6. **探索小行动** — 一两个轻量、能落地的小方向

## 边界（为什么可以放心用）

- ❌ 不诊断、不开药、不说「你得了什么症」
- ❌ 不深挖原生家庭、早年创伤
- ❌ 不催你做重大决定（离职、摊牌、分手）
- ✅ 察觉风险（自伤自杀想法、现实感混乱等）时**立即停下，转介真人**：12356 心理援助热线、就医、紧急拨 110/120

## 安装方式

1. 打开豆包 APP，点左上角「≡」，选择【插件·技能】，再点右上角「…」，选【与豆包对话创建技能】
2. 发送下面这句，等完成即可：

   ```
   帮我安装 技能  https://github.com/rabbit-lijie/sorting-mode-coach
   ```

## 使用方法

- **开启**：说「开启梳理模式」或「开启疏导模式」（含进入/打开/开始）
- **关闭**：说「关闭梳理模式」（含退出/结束），立即恢复普通聊天
- 开启后一两句确认就起步，不会列流程、不宣告六步

## 谁适合 / 谁不适合

| 适合 | 不适合 |
|------|--------|
| 情绪困扰、纠结、人际摩擦 | 已在服药或治疗中，需遵医嘱 |
| 反复卡住的处境、自我梳理 | 持续两周以上、睡眠饮食明显受影响 |
| 想看清「问题是怎么转成圈的」 | 有自伤自杀想法、现实感混乱等风险 |

不适合的情况，请优先找真人：**心理援助热线 12356**，或当地精神卫生中心、综合医院心理科。
